""`, `referenceRowId = finding.referenceRowId ?? null`. The crew lane should use the same mapping. The modifier-touch rule keys on `#modifier.<optionId>` in that id.
- Judgment calls for the orchestrator: (1) agent-cancel exposure counts agent-channel lines of any status (the packet did not restrict it); (2) a refunded order's lines count as at-risk but not as prospective exposure (prospective is fulfilled orders only, as specified); (3) `refund_cents` must be 0 on non-refunded orders, and allocation targets must be lines of the order.
- No modifier findings exist on the bundled drifted pair (its feed carries no menu fields), so modifier touching is covered by hand-built tests only.
- Modifier option ids in orders are drawn from the item-level lists, so a variation of an item can carry any of that item's options.
