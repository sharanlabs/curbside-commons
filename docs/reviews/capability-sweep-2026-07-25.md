# Capability sweep — delivery lane + evals harness — 2026-07-25

**Method:** read-only parallel audit (session 34, `/claude-os` live estate-test run). Each surface was
audited against the claims the repo makes about it, then every finding was to be adversarially
re-verified by an independent agent.

## Harness failure — recorded, because it bounds what this record covers

The sweep was launched as a 16-agent fan-out. **14 of 16 agents died on the session usage limit**
(~1.22M subagent tokens spent; 2 usable results). The three architecture-decision lanes — (b)
report-hash normalized projection, (a) E2/E4 re-arm-or-retire, (e) presentation posture — returned
`null` and **were never run**. The CLI, site, and MCP surface sweeps also died.

The adversarial verification stage died with them, so **the findings below carry their reporting
agent's evidence but NOT an independent second verification** — except where re-verified by hand
(noted per finding). The estate's own standing lesson already said "stagger background fan-outs";
it was hit anyway, and the replacement heuristic (≤5 agents per batch, read results before the next
batch) is now recorded in `~/claude-os/tasks/lessons.md`.

**This record exists because the surviving results were valuable and lived only in a workflow journal
that no clone would carry.**
