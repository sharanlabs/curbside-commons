## Root cause of MY defect — the finding that generalizes

The original M2 bug was signatures that were too LOOSE: keywords with no context requirement. My fix
inverted it — **three guards excluded whole grammatical POSITIONS rather than specific benign SHAPES**,
and every one was defeated by a one-word rephrase. Precision work is deceptively dangerous because it
goes green: each narrowing removes a false positive *and* silently creates a place an attacker can stand.

**Tightening a detector is itself a change that requires adversarial review.** It is not a safe,
monotonic cleanup. This is now pinned as the `M2-GATE3` suite so the nine bypasses cannot reopen.
