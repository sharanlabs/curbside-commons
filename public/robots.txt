# Curbside Commons — robots posture, decided 2026-07-25 (presentation lane (e)).
#
# INDEXABLE BY DESIGN. This is a portfolio prototype; it exists to be read by
# people evaluating the work, so a blanket noindex would defeat its only
# purpose. The honesty obligation is met the way it is everywhere else on this
# site — by labelling, not by hiding: every page's chrome, the footer-linked
# /docs "what is real" page, and the social card all state
# prototype-on-simulated-data on their face.
#
# Nothing is disallowed, because nothing superseded is served any more. The
# archived first-generation module was removed from the site on 2026-08-02 and
# its URLs now return the site's 404; a Disallow rule naming a path that does
# not exist is stale instruction, and stale instruction is how a crawler is
# taught something untrue about a site. If superseded material is ever served
# again, it gets a Disallow line again — an indexed stale page is how a claim
# outlives the correction that replaced it.
#
# No Sitemap: line — no sitemap route exists, and naming one that 404s is worse
# than naming none (a crawler reads the dangling reference as a site defect).
#
# Static file rather than an app/robots.ts route: this site is a static export
# (next.config.ts output: "export"), which cannot collect a dynamic metadata
# route — proven by a build failure, not assumed.
